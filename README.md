# Portafolio · Anais Valverde

Portafolio personal de desarrolladora Full Stack con foco en backend (Java / Spring Boot).
Hecho con Next.js (App Router), TypeScript y Tailwind CSS.

## Editar el contenido

Todo el contenido vive en `data/`, no hace falta tocar los componentes:

- `data/profile.ts` – datos personales, LinkedIn, educación y stack.
- `data/experience.ts` – experiencia laboral.
- `data/projects.ts` – proyectos.

## Correr en local

```bash
npm install
npm run dev
```

Abre http://localhost:3000.
